# 2026-04-20 Phase 3 증적

## 구현 요약

- `SocketHandler`에 전역 메모리 계수 보정, handler/global FileCache quota, stronger drain 판정, timeout clear, pressure relief hook을 추가했다.
- `ClientHandlerPool`, `TunnelClient`의 대기 큐에 세션별/풀별 상한을 추가하고 overflow 시 offending session만 fail-closed 하도록 바꿨다.
- `TunnelServer`에 미인증 handshake deadline과 unauthenticated connection cap을 추가했다.
- `EndPointClientPool`, `ExternalPortServerPool`은 `dispose()`/timeout cleanup과 delayed tracking removal로 수명주기 race를 줄였다.
- `HttpHandler`는 body rewrite 경로에서 inflate limit 초과 시 rewrite를 bypass하도록 변경했다.
- `ServerOptionStore`는 신규 설치 기본 `bufferLimitOnServer`, `bufferLimitOnClient`를 `8MiB`로 정규화한다. `-1`은 unsafe override로 유지된다.
