- 신규 설치:
  - admin console은 loopback + TLS 기본값 유지
  - protocol v2 identity 사용
  - HTTP `Origin` reflection 기본 비활성화
- 기존 설치:
  - unset `replaceAccessControlAllowOrigin`는 즉시 깨지지 않도록 legacy `true` 유지

  - mixed rollout 이후 `mtls-strict` cutover 가능
