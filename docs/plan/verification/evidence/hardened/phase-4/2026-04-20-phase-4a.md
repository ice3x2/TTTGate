# 2026-04-20 Phase 4A 증적

## 구현 요약

- `CtrlPacket`, `DataStatePacket`에 v2 handshake/data-binding 확장 필드를 추가했다.
- `TunnelServer`는 `trustedClients` 기반 `clientId` 인증, challenge/response proof-of-possession, handshake state/packet ID invariant, mixed/strict mode 분기를 적용한다.
- `TunnelClient`는 `clientId`, `clientSecret`, `displayName`, verified TLS 옵션을 사용해 v2 handshake를 수행한다.
- `ClientHandlerPool`은 v2 세션에 대해 one-time binding token을 발급하고 data channel attach 시 토큰을 검증한다.
- `TTTServer`, `ServerOptionStore`, `ClientApp`은 `controlProtocolMode`, `trustedClients`, `allowedClientIds`, TLS client options를 정규화한다.
- `TlsOptionsFactory` 기본값은 TLS 사용 시 `rejectUnauthorized=true`로 변경했다.
- 신규 설치 기본 control key는 공용 기본값 대신 랜덤으로 생성된다.
- `allowLegacyControlAuth`가 기본 `false`라서 legacy shared-key control auth는 명시적 opt-in 없이는 거부된다.
- v2에서는 full control/data handler ID를 메타로 운반해 16비트 header 한계를 넘는 경우도 세션을 유지한다.
