# 2026-04-19 Phase 2A 증적

## 범위

- 관리자 정적 자산 경로 탈출 차단
- unknown `/api/*` GET 정적 fallback 차단
- first-login bootstrap token 강제
- `/api/emptyKey` 제거
- 세션 토큰 CSPRNG 전환
- bcrypt 기반 비밀번호 저장과 legacy hash 자동 마이그레이션
- 로그인 실패 지연과 rate limit 추가
- 신규 설치 기본 `adminBindHost=127.0.0.1`, `adminTls=true`
- secret redaction 및 비밀 파일 `0600` 저장
- `-reset false` destructive reset 회귀 제거

npm run build
npm test -- --runInBand
