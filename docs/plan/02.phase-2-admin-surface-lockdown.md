# Phase 2: 관리자 면 즉시 차단과 비밀 관리

## 목표

원격 무인증 장악 경로를 가장 먼저 제거한다. 이 Phase는 관리자 서버 path traversal, 초기 관리자 bootstrap, bind/TLS 기본값, 세션/비밀 관리, `-reset false` 기능 버그를 우선 처리한다.

## 선행 조건

- [x] Phase 1 baseline 테스트가 모두 통과했다.
- [x] 관리자 정상 흐름 기준선 테스트가 있다.
- [x] path root override와 temp config/cert fixture가 준비되어 있다.

## 테스트

### Given-When-Then 시나리오

1. 정상 케이스
   - Given 정적 자산 `index.html`이 존재한다
   - When `/`를 요청한다
   - Then `200`과 자산이 반환된다
2. 정상 케이스
   - Given bootstrap token이 발급된 신규 설치 상태다
   - When 로컬 초기화 요청을 올바른 token과 함께 보낸다
   - Then 관리자 비밀번호가 설정되고 세션이 발급된다
3. 예외 케이스
   - Given `../config/.key`를 포함한 요청이 있다
   - When 관리자 서버가 요청을 처리한다
   - Then `403` 또는 `404`로 거부되고 파일은 노출되지 않는다
4. 예외 케이스
   - Given bootstrap이 끝나지 않은 서버에 원격 클라이언트가 직접 로그인 요청을 보낸다
   - When 서버가 요청을 검증한다
   - Then 요청은 거부되고 초기 관리자 상태는 바뀌지 않는다
5. 경계값 케이스
   - Given 여러 번 잘못된 비밀번호가 연속으로 전달된다
   - When 로그인 rate limit을 초과한다
   - Then 일정 시간 추가 시도가 거부된다
