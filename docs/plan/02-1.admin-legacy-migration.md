# 관리자 레거시 모드 마이그레이션 가이드

## 대상

- 기존 설치에서 관리자 콘솔을 평문 HTTP로 운영 중인 경우
- 기존 설치에서 관리자 콘솔을 `0.0.0.0`, 공인 IP, 비-loopback 주소에 바인드한 경우

## 2026-04-20 기준 정책

- 신규 설치 기본값
  - `adminBindHost=127.0.0.1`
  - `adminTls=true`
- 기존 설치는 insecure admin 정책을 그대로 기동할 수 없다.
- 정말 필요한 경우에만 **프로세스 1회 실행 동안** explicit legacy 플래그로 예외를 허용한다.

## 레거시 예외 플래그

- `-allowLegacyAdminHttp`
  - `adminTls=false` 상태를 1회 허용한다.
- `-allowLegacyAdminRemote`
  - `adminBindHost`가 loopback이 아닌 상태를 1회 허용한다.

둘 다 필요한 경우:

```sh
TTTGate server -allowLegacyAdminHttp -allowLegacyAdminRemote
```

## 권장 마이그레이션 순서

1. 관리자 콘솔을 로컬 접근으로 바꾼다.
   - `adminBindHost`를 `127.0.0.1`로 변경한다.
   - 운영상 원격 접근이 필요하면 SSH tunnel 또는 별도 reverse proxy/mTLS 경로를 사용한다.
2. 관리자 TLS를 켠다.
   - `adminTls=true`를 적용한다.
   - 필요한 경우 관리자 인증서를 교체한다.
3. 레거시 플래그 없이 서버를 재기동한다.
4. 로그인/세션/정적 자산/설정 변경 흐름을 확인한다.

## 운영 메모

- 레거시 플래그는 설정 파일에 저장되지 않는다.
- 레거시 플래그는 긴급 복구용 예외다. 상시 운영 기본값으로 사용하지 않는다.
- 서버가 `Refusing insecure admin policy` 오류로 시작을 거부하면, 설정을 secure-by-default로 바꾸거나 위 플래그를 명시적으로 추가해야 한다.

## 점검 체크리스트

- [ ] `adminBindHost`가 `127.0.0.1` 또는 `::1`인가
- [ ] `adminTls=true`인가
- [ ] 레거시 플래그 없이 서버가 정상 기동하는가
- [ ] 관리자 로그인과 세션 검증이 정상인가
- [ ] 운영 절차서에서 원격 평문 admin 접근을 제거했는가
