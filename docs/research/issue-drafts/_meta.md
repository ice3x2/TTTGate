```

## 근거
- `파일:행` — 해당 코드가 하는 일

## 재현 조건
언제 발생하는가.

## 영향
사용자가 무엇을 겪는가.

## 권고
어떻게 고치는가.

## 검증 상태
- 기존 테스트 커버: 없음 / 있음(파일명)
- 도입 시점: 기존 / 신규
- 확인 방법: 코드 확인 / 실행 재현

---
출처: `docs/research/2026-09-05-tttgate-full-inspection.md` §N
```
