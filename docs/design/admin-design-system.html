Signal Ops is the visual doctrine for the TTTGate admin surface. Background is strictly black & white on a pure white page; grays carry a faint blue undertone to read cool, not muddy. Color is reserved for meaning: 붉은 브릭 red as the signal, pine green for active states, blood red for destructive actions, ink navy for info — plotted on a 32 px grid. Typography unifies Latin and Korean on Noto Serif KR (display) and Noto Sans KR (UI), with JetBrains Mono reserved for data. Emphasis is signal color plus weight — never synthetic italic.

Doctrine

Every color carries exactly one meaning. A button is brick red only when the next click is the one the operator came here for. A row glows pine green only while something is actually alive. If everything is highlighted, nothing is.
