`TTTGate` reads runtime configuration from this directory.

- Server runtime file: `config/server.yaml`
- Client runtime file: `config/client.yaml`
- Admin bootstrap token: `config/.bootstrap-token`
- Admin password hash: `config/.key`

Tracked sample files:

- `config/server.sample.yaml`
- `config/client.sample.yaml`

Copy the sample you need to the runtime filename and then replace placeholder secrets before starting the process.
